# 🚀 Terminal Portfolio - GHOSTGAMR

A modern, interactive terminal-style portfolio website built with React, TypeScript, and Tailwind CSS. Experience my professional journey through a nostalgic command-line interface with smooth animations, easter eggs, and mini-games.

## 🚀 Quick Start

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/GhostGamr/terminal-portfolio.git

# Navigate to project directory
cd terminal-portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build for Production

```bash
# Create production build
npm run build

# Preview production build
npm run preview
```

## 🎯 Available Commands

### 📋 Core Commands

| Command | Description |
|---------|-------------|
| `banner` | Display the ASCII art banner with GHOSTGAMR branding |
| `about` | Learn about my background, interests, and passion for development |
| `services` | Explore my professional services and technical expertise |
| `projects` | Browse through my featured projects and portfolio |
| `achievements` | View my certifications, accomplishments, and milestones |
| `contact` | Get my contact information and social media links |
| `help` | Show all available commands with descriptions |
| `clear` | Clear the terminal screen |
| `echo <message>` | Echo back any message you type |

### 🎮 Fun Commands & Easter Eggs

The `fun` command reveals a collection of interactive games and easter eggs:

| Command | Description |
|---------|-------------|
| `fun` | Overview of all available games and easter eggs |
| `cowsay <message>` | ASCII cow that "says" your custom message |
| `matrix` | Experience the iconic Matrix digital rain animation |
| `snake` | Play the classic Snake game right in the terminal |
| `fortune` | Get random inspirational quotes and fortunes |
| `konami` | Secret Konami Code easter egg (try the classic sequence!) |

### 🎲 Easter Egg Details

#### 🐄 CowSay
```bash
cowsay Hello World!
```

- Classic ASCII cow with speech bubbles
- Dynamic bubble sizing based on message length
- Authentic terminal cow experience

#### 🔢 Matrix Rain

- Animated digital rain effect inspired by The Matrix

#### 🐍 Snake Game

#### 🔮 Fortune Teller

## 📁 Project Structure

```
src/
├── components/
│   ├── CommandInput.tsx      # Terminal input component
│   ├── Terminal.tsx          # Main terminal wrapper
│   ├── TerminalHeader.tsx    # Terminal window header
│   ├── TerminalOutput.tsx    # Output display component
│   ├── TypewriterText.tsx    # Typewriter animation component
│   └── games/
│       ├── CowSay.tsx        # ASCII cow game
│       ├── Fortune.tsx       # Fortune teller
│       ├── KonamiCode.tsx    # Konami code easter egg
│       ├── MatrixRain.tsx    # Matrix rain animation
│       └── SnakeGame.tsx     # Snake game
├── hooks/
│   └── useTerminal.ts        # Terminal state management
├── types/
│   └── terminal.ts           # TypeScript type definitions
└── utils/
    ├── commandExecutor.ts    # Command processing logic
    ├── commands.ts           # Command utilities
    └── constants.ts          # App constants and configuration
```
